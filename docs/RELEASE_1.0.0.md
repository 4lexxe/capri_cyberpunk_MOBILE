# CAPRI MOBILE // 1.0.0

Tu compañera cyberpunk para Android, con personalidad y voz en español latino.

## Descargar

**[DESCARGAR APK COMPLETO CON QWEN](https://github.com/4lexxe/capri_cyberpunk_MOBILE/releases/download/v1.0.0/Capri-Android-1.0.0-completa.apk)**

El APK completo incluye los dos modelos Qwen y el perfil de voz latino. Ocupa aproximadamente 910 MB; reserva cerca de 2 GB para instalar y preparar la voz. Android 8+ de 64 bits; Qwen necesita Android 12+. En versiones anteriores utiliza voz Android.

## Incluye

- Mascota flotante de **100 dp por defecto**, con animaciones, arrastre y encuadre sentado.
- Botón central para **chat de voz por turnos sin abrir el chat**. Micrófono autorizado, notificación para detenerlo y escucha pausada mientras responde Capri.
- Globos de mensaje temporales con **×** para cerrarlos.
- Voz Qwen local preconfigurada: ritmo 109%, filtro robótico suave 52% del control y volumen 73%. Voz Android como alternativa.
- Capturas **manuales**: una imagen por autorización de Android, con cierre de la captura antes del envío. Sin servicio de Accesibilidad en esta distribución.
- Conexión mediante cuenta ChatGPT habilitada, claves propias de OpenAI/Gemini/Claude o servidor compatible. Los servicios externos aplican sus condiciones y límites.

## Instalación y configuración

1. Descarga **completa.apk** para una primera instalación. Si ya conservas los modelos, puedes usar **actualizacion.apk**.
2. Abre el APK y permite instalar desde tu navegador/Archivos sólo si Android lo solicita. Instala encima de Capri para conservar datos: el código interno es 10 aunque el nombre público sea 1.0.0.
3. Espera la preparación local de Qwen. Configura y prueba tu proveedor en Mainframe; Qwen no requiere una clave de voz, pero la conversación y visión necesitan una conexión propia.
4. Concede Mostrar sobre otras apps para la mascota, y micrófono sólo al iniciar una sesión de voz.

## Avisos y verificación

Proyecto de fans **no oficial**, basado en Capri Desktop de Lachy. Android/Play Protect puede pedir analizar un APK externo; mantén esa protección activa. Si aparece un bloqueo de seguridad, cancela y reporta el mensaje exacto en Issues. No se afirma aprobación de Google.

Se incluyen SHA256SUMS.txt y el código fuente. Los pesos grandes se entregan dentro del APK completo y su descarga reproducible está fijada en models.lock.json. No se publican claves privadas ni credenciales.

Validación local: 58 pruebas de lógica, 14 de dispositivo en emulador API 35 y comprobaciones de firma, modelos y alineación. El reconocimiento del test de voz se simuló mediante un servicio Android de prueba; falta medir la experiencia real de micrófono y Qwen en cada teléfono. No se promete voz instantánea en todos los equipos.
